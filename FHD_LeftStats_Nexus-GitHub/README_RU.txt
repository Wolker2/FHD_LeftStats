FHD_LeftStats 0.5 ALPHA — Космические рейнджеры HD 2.1.2500

УСТАНОВКА
Закройте игру. Содержимое архива распакуйте в папку с игрой, где лежит
Rangers.exe, с заменой файлов предыдущей версии. Включите FHD_LeftStats
в разделе FHD_MODS. Полностью перезапустите игру и загрузите сохранение.

ИСПРАВЛЕНИЯ В 0.5
Исправлена проверка режима при первом открытии окна корабля. Ранее скрипт
смотрел на ещё не обновлённый флаг активности трюма и пропускал его открытие.
Теперь он проверяет штатную вкладку статистики, которая служит индикатором
режима, и включает трюм до пересчёта интерфейса движком.
Исправлен слой левой панели: в 0.4 она рисовалась под фоновым буфером.
Теперь порядок такой: фон, левая статистика, оборудование с правым трюмом.

РАСКЛАДКА ПО ОБРАЗЦУ
При 1920×1080 левая рамка начинается в точке 355×208, правая — 1045×205.
Левая рамка размером 328×598 и нижние кнопки отражены; портрет, текст и навыки
читаются обычно. Статистика показывается отдельно от переключаемой вкладки.
Кнопки с ящиком сохраняют обе панели открытыми, крестики закрывают окно.
Оборудование, геометрия и предметы правого трюма остаются на исходных местах.
Изменения размещены внутри мода; оригинальные CFG, DATA и EXE не заменяются.

ПРОВЕРКИ
Две новые проверки сначала воспроизвели ошибки 0.4: трюм скрывался после
первого входа; левая панель рисовалась раньше фонового буфера и перекрывалась им.
В 0.5 обе проверки проходят. Использованы исходные машинные инструкции
сортировки слоёв, обхода отрисовки, переключения трюма и пересчёта вкладок.
Проверены первое открытие, два повторных и обновление окна после действий.
Также проходят проверки границ, CFG/DAT, изображений и штатных привязок.

Это эмуляция отдельных функций с тестовыми методами объектов интерфейса.
Полная игра не запускалась; фактическая отрисовка, скрипты и взаимодействие
с предметами требуют проверки в игре. Сборка остаётся ALPHA.
Малые разрешения, другие контексты формы Ship и моды, изменяющие ML.Ship,
не проверены. В других контекстах Ship статистика также может показываться.

ИСХОДНИКИ
SOURCE содержит конфигурацию, исходные изображения, сборщик и проверки.
Python 3 + Pillow:
  python SOURCE/build.py
  python SOURCE/verify_draw_bounds.py
  python SOURCE/verify.py
  python SOURCE/verify_dual_panels.py
Опциональные verify_native_switch.py и verify_native_lifecycle.py требуют
pefile, unicorn и оригинальный Rangers.exe с контрольной суммой, указанной
в TECHNICAL_NOTES.txt. EXE в архив не включён.

УДАЛЕНИЕ
Закройте окно корабля, сохранитесь, отключите мод и перезапустите игру.
Затем можно удалить папку Mods\FHD_MODS\FHD_LeftStats.
